# 申请百度 AI 搜索 Key 教程

> 目标：拿到一个「百度 AI 搜索」的 API Key，让网站能实时联网搜索竞赛信息。
> 全程免费（有每日免费额度），实名认证即可，约 10 分钟。

---

## 第一步：注册 / 登录百度智能云

1. 打开 **https://cloud.baidu.com/**
2. 右上角「登录」。有百度账号（百度网盘、贴吧账号都算）直接登录；没有就注册一个。
3. 首次使用会提示「实名认证」，选**个人认证**（身份证，免费、快）。

---

## 第二步：开通「百度 AI 搜索」服务

1. 登录后打开千帆平台：**https://qianfan.cloud.baidu.com/**
2. 搜索「**百度搜索**」或「**AI 搜索**」，找到该能力。
3. 点「**开通**」/「**开通后付费**」。
   - 百度 AI 搜索**每天有免费额度**，个人和小规模使用绰绰有余。

---

## 第三步：创建 API Key

1. 千帆平台右上角头像 → 「**API Key 管理**」或「**密钥管理**」。
2. 点「**创建 API Key**」（或「新建密钥」）。
3. 会生成一串类似 `bce-v3-...` 的字符，这就是 key。
4. **立刻复制保存好**，部分平台关闭后只显示一次。

---

## 第四步：配置 key

把 key 通过 secret 方式配置到 Cloudflare（见 [`部署到Cloudflare.md`](部署到Cloudflare.md)）：

```bash
wrangler secret put BAIDU_API_KEY
```

> ⚠️ **不要把 key 写进代码、README、或任何会推送到公开 GitHub 仓库的文件里。** 本项目已通过 `.gitignore` 排除敏感文件。

## 常见问题

**Q：提示要实名认证？**
A：正常，个人实名认证用身份证，几分钟通过，免费。

**Q：会不会扣我钱？**
A：免费额度内不扣。建议先不开「自动充值」，用免费额度就够。

**Q：能换别的搜索服务吗？**
A：后端设计上可替换搜索服务（如 Serper 等），需要时另外配置。
